# 最初のバージョンはサーバーを持たずlocalStorageに保存する

最初のバージョンではサーバー側の保存もログインも用意せず、プランはブラウザのlocalStorageに保存する。夫婦での共有や端末間の移動は、JSONファイルの書き出しと読み込みで行う。主な利用者は開発者本人の世帯で、アカウント管理やサーバー運用の手間をかけずに、まずシミュレーションの中身を早く使える状態にしたいため、この形にした。プランのデータはそのままJSONとして扱える形にしておき、後でログインとサーバー保存（Cloudflare D1）を追加するときに、同じ形のまま移せるようにする。

## Consequences

- 別の端末やブラウザでは、書き出し・読み込みをしない限りプランは見えない。ブラウザのデータを消すとプランも消える。
- キャッシュフローの計算はすべてブラウザで行う。サーバーに計算を任せる前提の設計にはしない。
