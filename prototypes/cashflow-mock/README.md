# キャッシュフローシミュレーター モック（PROTOTYPE・使い捨て）

`.scratch/cash-flow-simulator-v1/spec.md` の画面の流れを確かめるための使い捨てモック。本実装（SvelteKit）にはコードを持ち込まない。

## 起動

`index.html` をブラウザで開く（ダブルクリック）。

## 確かめたいこと

- プラン一覧：作成・サンプル作成・名前の変更・複製・削除・JSONの書き出しと読み込み
- 入力：左サイドバー付きの10ステップ、エラーのある大項目に赤い点、最後のステップの「キャッシュフロー表を出力」
- 表：大項目の行の ▸ で小項目が開く、見出しの固定、5年ごとの間引き表示、マイナスの赤字
- 印刷：A4横向き・1ページ15年分・大項目の行だけ

## 入力画面のレイアウト（画面下のバー、または ← → キーで切り替え）

- `?variant=A`：1ステップ1画面（仕様どおり）
- `?variant=B`：全ステップを1ページに縦に並べる
- `?variant=C`：1ステップ1画面 ＋ 右側に表のライブプレビュー

## 注意

- 計算は仕様を簡略化している。数値の正しさはこのモックでは確かめない（本実装でテストを書きながら作る）
- データは localStorage の `PROTOTYPE_cashflow_plans` に保存される。消してかまわない
